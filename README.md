# 🚀 Khadeer Shaik - 3D Developer Portfolio & AI Platform

A modern, high-performance **3D interactive developer portfolio and AI platform** built with **Next.js**, **React**, **TypeScript**, **Three.js**, **GSAP**, **Tailwind CSS**, and **WebGL**.

## ✨ Features

- **3D / WebGL Experience**: Immersive 3D interactive avatar character powered by **Three.js** and **GSAP**.
- **Interactive Play Mode (Chess + AI Chat)**: Integrated chess engine (Stockfish / RedoxChess) paired with an AI conversational assistant powered by **Groq / Llama 3.3**.
- **Full-Stack Project Showcase**: Highlights production-grade applications, AI chatbot solutions, and web architectures.
- **Responsive & Modern Design**: Dark mode aesthetic with glassmorphism, fluid typography, smooth scrolling (Lenis), and ambient background glows.
- **Resume Download**: Integrated resume download (`KHADEER_SHAIK_Devloper.pdf`).

---

## 🧰 Tech Stack

- **Frontend**: Next.js (App Router), React 18, TypeScript, Tailwind CSS, GSAP, Lenis
- **3D & Animation**: Three.js, React Three Fiber, React Three Drei, Canvas
- **Backend / APIs**: Node.js, Express, Flask, FastAPI, Groq LLM API
- **AI & Tools**: Chess.js, Stockfish, Lucide / React Icons

## 🚀 Getting Started

### 1) Clone Repository

```bash
git clone https://github.com/FarhanOnCode/test.git
cd test
```

### 2) Install Dependencies

```bash
npm install
```

### 3) Set Up Environment Variables

Create a `.env` file in the root directory (refer to `.env.example`):

```env
GROQ_API_KEY=your_groq_api_key_here
```

### 4) Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 5) Build for Production

```bash
npm run build
```
